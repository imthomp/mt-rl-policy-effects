# Tatoeba English–German candidate manifests

The original `train_seed*.jsonl` files are exploratory candidate subsets. The active revised protocol uses `protocol_v1/`: one 2,048-pair shared training set, 1,024 calibration pairs, 1,024 development pairs, and a 2,048-pair in-domain final test. These were drawn from the eligible pair pool built from the official Tatoeba detailed-sentence and translation-link exports dated 2026-10-31. Both sentences in each pair have at least one positive review and no negative review; Tatoeba describes review data as experimental, so this filter is not a quality guarantee. Exact WMT23/WMT24 source/reference text matches were excluded.

Each JSONL row preserves the English and German Tatoeba sentence IDs and contributor names. Tatoeba states that its weekly text exports are under CC-BY 2.0 FR and notes that some sentences are also available under CC0. The detailed export used here has no row-level license field, so the audit treats selected rows under the export-level CC-BY 2.0 FR terms and does not claim sentence-specific CC0 status. The FAQ asks projects to identify Tatoeba, link to `https://tatoeba.org`, and name the license; the usage guidance says to cite sentence authors. Retain contributor metadata and the license notice if rows are redistributed. See the [official downloads page](https://tatoeba.org/en/downloads), [attribution FAQ](https://en.wiki.tatoeba.org/articles/show/faq), and [processing guidance](https://en.wiki.tatoeba.org/articles/show/using-the-tatoeba-corpus).

Suggested project-level attribution: “Training text includes selected English–German sentences from Tatoeba (https://tatoeba.org), released under CC-BY 2.0 FR (https://creativecommons.org/licenses/by/2.0/fr/). Sentences were filtered using the documented review rule, NFC-normalized, stripped, and selected as recorded in `candidate_audit.json`; contributor names and sentence IDs are retained per row.” This does not replace retaining author attribution when publishing or redistributing sentence-level data. See the project's [data/model notice](../../docs/DATA_MODEL_NOTICE.md) for the full attribution and pinned model information.

The protocol splits are disjoint by sentence ID and exact normalized text across train, calibration, development, and test; `protocol_v1/split_audit.json` records pairwise overlaps and each manifest hash. Three optimization seeds reuse the same training split so seed variation does not also change the data subset. The source files, SHA-256 hashes, WMT overlap audit, full eligible pair pool, and original exploratory manifests are recorded in [candidate_audit.json](candidate_audit.json). The deterministic builders are [prepare_tatoeba_manifests.py](../../src/prepare_tatoeba_manifests.py) and [prepare_tatoeba_protocol_splits.py](../../src/prepare_tatoeba_protocol_splits.py).
