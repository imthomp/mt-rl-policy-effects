# Raw Tatoeba exports

Downloaded from Tatoeba's official weekly export endpoints on 2026-10-31. The files are used only to build the candidate English–German manifests; no audio was downloaded. File URLs and SHA-256 values are recorded in `../tatoeba_en_de/candidate_audit.json`. Tatoeba's downloads page states that the text exports are under CC-BY 2.0 FR (with some sentences also available under CC0). Detailed rows retain sentence IDs and contributor names; link rows retain translation relations; the reviews export supplied the quality filter.
